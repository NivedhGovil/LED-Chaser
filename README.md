## LED Chaser

This project is an **LED Chaser**: a series of 10 LEDs that light up in a sequence. 

## In this repository
Bill Of Materials.csv : Bill of Materials, all parts required and their descriptions.  <br> 
Journal.md: A journal on my progress with making this project. <br> 
schematic.png: A screenshot of the Schematic <br> 
PCB_PCB_LED-Chaser-New_2026-10-12.json: The EasyEDA export of the PCB in json <br> 
PCB_PCB_LED-Chaser-New_2026-10-12.kicad_pcb: The PCB file of kicad. <br> 
SCH_LED-Chaser-New_2026-10-12.json: The EasyEDA export of the schematic in json.<br> 

*No firmware needed.*
