## LED Chaser

This project is an **LED Chaser**: a series of 10 LEDs that light up in a sequence. 

## In this repository
BOM.csv : Bill of Materials, all parts required and their descriptions.  <br> 
PCB : A folder containing: <br> 
<li> the zipped Gerber file. </li>
<li> A screenshot of the PCB </li>
<li> The schematic of all components in a pdf </li> <br> 

*No firmware needed.*

# My Learnings

This is my first PCB and it was an insighting experience. I learnt routing, vias, drawing schematics, etc.
